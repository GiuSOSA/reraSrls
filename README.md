# RERA SRLS

Landing page for RERA SRLS, a reseller of industrial machinery (lathes, presses,
milling machines, welding equipment, forklifts, and more).

Plain HTML/CSS/JS, no build step required. Open `index.html` in a browser,
or serve the folder locally:

```
python3 -m http.server
```

## Structure

- `index.html` — hero section + machine category picker + about/contact sections
- `style.css` — dark theme styling
- `script.js` — click handling for the category cards

All copy and category details are placeholders — replace with real inventory,
pricing and contact info.
